# ชุดสร้างคลิปเปิดตัว CBE Reporting

เอกสารนี้รวมทุกอย่างที่ใช้สร้างคลิป `CBE_Reporting_Launch.mp4` (1:46 นาที) เพื่อนำไปสร้างซ้ำหรือแก้ไขในแชทใหม่

## 1. วิธีใช้ในแชทใหม่

1. แนบไฟล์ 3 ไฟล์นี้ในแชทใหม่
   - `cbe-video-kit.zip` (ไฟล์นี้)
   - ไฟล์เสียงพากย์ `.wav`
   - ไฟล์เพลง `.mp3` (เพลงทั้งสองไฟล์อยู่ใน zip แล้ว ในโฟลเดอร์ `audio/`)
2. คัดลอกข้อความในหัวข้อ 2 ไปวางเป็นคำสั่ง

## 2. คำสั่งสำหรับวางในแชทใหม่

```
ช่วยสร้างคลิปเปิดตัวระบบ CBE Reporting จากชุดไฟล์ cbe-video-kit.zip ที่แนบมา
- อ่าน README.md ใน zip ก่อน แล้วรัน build.sh ตามที่เขียนไว้
- ใช้ repo GitHub neerablejompon-gif/CBE (clone มาที่ /home/claude/neerablejompon-gif/cbe)
- เสียงพากย์และเพลงอยู่ใน zip โฟลเดอร์ audio/
- ตัดเสียงพากย์หลังวินาทีที่ 91.0 ของไฟล์เสียง (มีคำว่า "หมายเหตุ" ติดมาท้ายไฟล์)
- สิ่งที่อยากแก้เพิ่ม: [ใส่ตรงนี้]
- ห้ามใช้ข้อมูลรายงานจริง ใช้ข้อมูลสมมติจาก gen.js เท่านั้น
```

## 7. ข้อควรรู้

- **ต้องใช้ repo:** โลโก้และหน้าระบบมาจาก repo `neerablejompon-gif/CBE` (`mockup/index.html`, `mockup/assets/`)
- **ฟอนต์บนหน้าจอระบบ:** ระบบจริงใช้ IBM Plex Sans Thai ที่โหลดจาก Google Fonts ถ้าแชทใหม่เข้าถึงไม่ได้ Chrome จะใช้ฟอนต์ไทยอื่นแทน ถ้าต้องการให้ตรง ให้แนบไฟล์ฟอนต์ไปด้วย
- **ห้ามเปิดการชะลอแอนิเมชันของ Chrome:** `rec.py` ตั้ง playbackRate = 1 ไว้แล้ว ถ้าตั้งค่าอื่น ตัวเลขที่นับขึ้นบนหน้าคะแนนจะติดลบ
- **บัญชีทดลองตั้งเดือนเป็น ก.ย.:** สคริปต์จึงตั้ง `S.month = curMonth()` ใหม่หลังเข้าระบบ
- **เวลาฉากผูกกับไฟล์เสียงชุดนี้:** ถ้าอัดเสียงใหม่ ต้องปรับเวลาใน `compose.py` (ส่วน `S = {...}` ท้ายไฟล์) ให้ตรงกับย่อหน้าใหม่
- **ไฟล์เสียงมีคำเกิน:** build.sh ตัดเสียงพากย์ที่วินาที 91.0 แล้ว (`atrim=end=91.0`) และลดระดับเสียงรวม −1.8 dB ให้ได้ประมาณ −15.5 LUFS
- **ปรับตาม UI รุ่นใหม่ (9 พ.ย. 2569):** หน้าคะแนนย้ายไปอยู่ในเมนู "ภาพรวมตัวชี้วัด" · ขั้นรายงานผลเหลือ 3 ขั้น (GAP แยกเป็นเมนู "แผนปรับปรุง GAP") · ปุ่มออกจากระบบอยู่ในเมนูผู้ใช้ (`[data-act=umenu]`) · แก้ `scenes.py` ตามนี้แล้ว
- **ถ้า UI เปลี่ยนอีก:** ฉากที่ล้มจะพิมพ์ `FAIL <ชื่อฉาก>` ให้ดูชื่อเมนู/ปุ่มใหม่ใน `mockup/index.html` แล้วแก้ locator ใน `scenes.py`
- **ใน repo:** สคริปต์ชุดนี้อยู่ที่ `video-kit/` (ไม่รวมไฟล์เสียงและ data.js ซึ่งสร้างใหม่ได้ด้วย `data/gen.js`)
