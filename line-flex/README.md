# LINE Flex Message: ต้นแบบการแจ้งเตือน (ยังไม่ได้เชื่อมระบบ)

| ไฟล์ | ผู้รับ | รอบ | เนื้อหา |
|---|---|---|---|
| `quarterly-executive.json` | ผู้บริหาร | รายไตรมาส | คะแนนเฉลี่ยเทียบเป้า, คาดว่าถึงเป้า, หลักฐานครบ, ระดับล่าช้า, คะแนนรายตัวชี้วัดพร้อมสีสถานะ, ตัวชี้วัดที่ควรเร่ง, ปุ่มเปิดภาพรวม |
| `monthly-owner.json` | ผู้รับผิดชอบตัวชี้วัด | รายเดือน | วันครบกำหนดส่ง, ความพร้อมส่ง, รายการที่ยังไม่ครบ 4 กลุ่ม (ตรงกับ "สิ่งที่ต้องทำ" ในหน้างานของฉัน), ปุ่มเปิดงานของฉัน |

- ค่าทั้งหมดเป็นข้อมูลสมมติชุดเดียวกับ `mockup/` ระบบจริงต้องสร้าง JSON จากข้อมูลในฐานข้อมูลตอนส่ง
- เกณฑ์สีสถานะ: เขียว = ถึงเป้า, ส้ม = ต่ำกว่าเป้าไม่เกิน 0.10, แดง = ต่ำกว่าเป้าเกิน 0.10, เทา = ไม่มีเป้า
- ส่งผ่าน Messaging API `POST https://api.line.me/v2/bot/message/push` ใส่ไฟล์นี้เป็นสมาชิกของ `messages` และต้องมี `userId` ของผู้รับ (ได้จากการให้ผู้ใช้เพิ่มเพื่อนบัญชี LINE OA แล้วผูกกับรหัสพนักงาน)
- ยังไม่ได้ทดสอบกับ LINE จริง ควรวางใน Flex Message Simulator ของ LINE Developers ก่อนใช้
- URL ในปุ่ม (`#overview`, `#my`, `#report`) เป็นตัวอย่าง ต้องปรับให้ตรงกับเส้นทางของระบบจริง
- ภาพจำลองที่ใช้ในคลิปอยู่ที่ `video-kit/v2/line/index.html` (`?v=exec` หรือ `?v=owner`)
