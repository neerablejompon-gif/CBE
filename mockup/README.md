# Mockup UX/UI · CBE Report Platform

ต้นแบบหน้าจอระบบรายงานผล Core Business Enablers 8 ตัวชี้วัด (SE-AM 2569) ธีมน้ำเงิน-ขาว Glassmorphism / Liquid glass เป็นไฟล์ HTML เดียว (vanilla JS ไม่มีไลบรารีภายนอก) ยังไม่เชื่อมกับ backend ใน `src/`

## สิ่งที่มีในต้นแบบ

| ส่วน | รายละเอียด |
|---|---|
| เข้าสู่ระบบ | บัญชีทดลองตามบทบาท: กปม. (Audit/Admin), ผู้บริหาร (ดูอย่างเดียว), ผู้รายงานรายตัวชี้วัด |
| สิทธิ์ | ผู้รายงานเห็นเฉพาะตัวชี้วัดของตน · SM/CM และ KM/IM มีผู้รายงานแยก แก้ได้เฉพาะส่วนของตน |
| ภาพรวม CBE | คะแนน 8 ตัวชี้วัดเทียบเป้า, สถานะส่งรายงานรายเดือน, งานรอตรวจ |
| Workspace ตัวชี้วัด | ภาพรวมคะแนน, Quality Gate, รายงานผลรายระดับ (ขั้นตอน แผน/ผล 12 เดือน, Minimum Requirement, ผลการดำเนินงาน, ข้อสังเกต กปม.), แผนปรับปรุง GAP, ทะเบียนหลักฐาน, ผลที่ผ่านมา |
| คะแนนรวม | SCM = (SM × 50 + CM × 50) ÷ 100 · KM&IM = (KM × 40 + IM × 60) ÷ 100 |
| พื้นที่ผู้ตรวจสอบ | รายการที่ส่งมาตรวจ + ระบบตรวจสอบเบื้องต้น (กฎ 10 ข้อ 5 ด้าน) ให้ กปม. ยืนยัน/ตัดข้อค้นพบ แล้วอนุมัติหรือส่งกลับพร้อมข้อค้นพบ |

## สร้างข้อมูลและเปิดดู (Windows PowerShell)

`data.js` สร้างจากแบบฟอร์มรายงานผล Excel เดิม (1 ไฟล์ต่อตัวชี้วัด) และ **ไม่เก็บใน repo** เพราะมีเนื้อหารายงานจริง

```powershell
# 1) แปลงแบบฟอร์ม Excel + โครงสร้าง SE-AM จาก src/Seed.gs เป็น mockup/data.js
powershell -ExecutionPolicy Bypass -File mockup\tools\forms-to-json.ps1 -Forms "<โฟลเดอร์แบบฟอร์มเดิม>" -Seed src\Seed.gs -Out mockup\data.js

# 2) เปิดเซิร์ฟเวอร์ในเครื่อง แล้วเข้า http://localhost:8790/
powershell -ExecutionPolicy Bypass -File mockup\tools\serve.ps1
```

- สคริปต์อ่านหัวคอลัมน์ตามชื่อ (ลำดับ, ระดับ, ค่าเกณฑ์, วิเคราะห์ GAP, ขั้นตอน, แผนผล, ต.ค.–ก.ย., Minimum Requirement, ชื่อหลักฐาน, ข้อสังเกต กปม. ฯลฯ) จึงรองรับแบบฟอร์มที่คอลัมน์ต่างกันเล็กน้อย
- ชื่อบุคคลในช่องผู้รับผิดชอบถูกแทนด้วย "ผู้รับผิดชอบตัวชี้วัด" และชื่อองค์กรถูกแทนด้วย "รัฐวิสาหกิจ"
- การแก้ไขในต้นแบบเก็บใน localStorage ของเบราว์เซอร์เท่านั้น

## ข้อสมมติที่ต้องยืนยัน

- แบบฟอร์ม CM ไม่มีน้ำหนักประเด็นย่อยและคะแนนประเมินตนเอง จึงใช้น้ำหนักเฉลี่ยชั่วคราว (รวม 50) และคะแนนจากระบบแทน
- สถานะรอบรายงานรายเดือนและเวลาส่งตรวจเป็นข้อมูลตัวอย่าง
- ผลประเมินย้อนหลังมีเฉพาะ RM
